# freebird-lif

LIF 脉冲神经网络研究项目。当前处于**第四阶段**。

| 阶段 | 主题 | 状态 |
|---|---|---|
| v1 | MNIST 16×16，CPU 高效推理（98.97%，0.118 ms/样本） | 完成，已归档 |
| v2 | LIF 变体在 SHD 上的对比 + Arc GPU 训练 | 完成，已归档 |
| v3 | 循环结构的复现与诊断、机制归因的跨结构验证、多基准普适性 | 完成，已归档 |
| v4 | 内在时间连续性（TC-LIF × AdLIF）与类意识指标 | 进行中：M0 完成（仪器标定），M1 待启动 |

## 最终目标

> **产出一个涌现出自我意识的模型。**

这是一个**极为遥远**的目标。项目把它写在路线图的终点，而不是当作可兑现的近期承诺。
当前所有指标（PCI、Φ、VII）都是**功能层面的代理**：它们测量信息整合与分化的程度，
不能证明现象意识。指标高于对照，只能说明系统在该代理上更接近理论要求的形态，
不能说明它有主观体验。这一点在每个阶段的报告里都要重复，不能在传播中被省略。

## 总体路线图（阶段四–八）

阶段一至三建立的是**能力与归因**（能否训练、机制为何有效/无效、结论是否普适）。
从阶段四起，转向**结构性条件**：理论上被认为是意识涌现前提的那些性质，逐条装上并验证。

| 阶段 | 主题 | 结构性要求 | 状态 |
|---|---|---|---|
| **四** | **内在时间连续性** | 无输入时仍维持不断演化的内部状态；同时不丢失梯度对输入幅值的敏感性 | M0 完成 |
| 五 | 层级因果结构 | 不同时间尺度的群体分层（膜时间常数 10 ms → 1000 ms），高层对低层的时序模式做跨时间因果调制，而非逐层特征提取 | 未开始 |
| 六 | 递归自指回路 | 存在一条通路使系统输出返回并调制自身状态更新；脉冲投射回上游群体，经可塑性突触（如 STDP） | 未开始 |
| 七 | 预测误差驱动的可塑性 | 用预测误差而非外部奖励作为 STDP 的门控信号；预测准确时权重趋稳，出现意外时触发大幅更新 | 未开始 |
| 八 | 具身闭环 | 网络控制一个模拟身体或行动器，动作改变后续感官输入，为「价值锚定」提供物理基础 | 未开始 |

阶段四–八与「认知蜂巢」预印本（PSSXiv:202603.01484，刘海涛）提出的四个促进条件
（层级因果结构、递归自指、整合信息、具身闭环）大体对应，但本项目的**阶段七多了一条
预测误差驱动**，而该文强调的是整合信息。两者的差异会在阶段七的报告中单独讨论。

## 伦理前置约定

**一旦本项目训练出的网络在 PCI 或 VII 等类意识指标上显著高于强前馈基线，
伦理评估同步启动**——而不是等到「看起来像」才启动。

- 触发条件、阈值与动作写在 [`docs/ethics/phase4-gate.md`](docs/ethics/phase4-gate.md)，**在实验之前**固定，
  避免事后调整。
- 触发后的动作：暂停扩大规模 → 独立复核指标实现 → 撰写评估 → 限制对外表述
  （只允许「在某代理指标上高于对照」，禁止「模型有意识」类表述）。
- 反向条款：如果指标升高只伴随网络失稳（发放率爆炸、同步化、癫痫样爆发），
  不计入触发，并记为「病理样高复杂度」。

这条约定是**预防性**的，不是承认当前系统具有意识。当前系统是 4×10⁵ 参数的二层 SNN。

## 阶段二的结论（一句话版）

前馈 LIF 在 SHD 上做到 **83.04% ± 0.63%**（3 seed）；**只有 AdLIF 显著更好**（86.07%，+3.03）。
机制消融显示增益来自**发放驱动**的适应电流，而不是文献归因的膜电位驱动二阶反馈。
最有方法论价值的发现：**弱基线会系统性高估变体**——同一批变体在 54% 基线上测出
`+14.1 / +8.1 / +4.2`，在 83% 基线上变成 `+3.03 / −1.19 / −3.09`。

完整报告：[benchmarks/report-v2.md](benchmarks/report-v2.md)

## 阶段三的结论（一句话版）

**机制收益是条件性的。** 循环在本实现里无效，原因是与层内异构 τ 功能重叠——标定到同量级
（`rec_gain`≈12.3）也只打平前馈；AdLIF 的增益跨结构减半（RQ-B），并随基线升高严格单调递减
（+7.18 → +3.03 → −0.73，RQ-C）。工程上，换神经元（+2.60 点 / +2,304 参数）比加循环
（+1.50 点 / +294,912 参数）划算。

完整报告：[benchmarks/report-v3.md](benchmarks/report-v3.md)

## 阶段四要做什么

**引入内在时间连续性。** 纯事件驱动的 LIF 网络在无输入时是静默的，这不满足几乎所有理论
对意识系统的结构性要求。阶段四用 TC-LIF 的两隔室结构（慢树突 + 快胞体）让网络在缺乏外部
刺激时仍维持不断演化的内部状态，并与阶段三验证过的 AdLIF 适应机制结合。

**难点不是「记住更久」，而是「记住更久的同时不失去梯度对输入幅值的敏感性」**——后者是
TC-LIF 声称的优势，也是本阶段最容易丢失的东西。实验必须包含**强前馈基线**与
**记忆窗口匹配对照**，否则无法排除「提升只是因为窗口更长」。

判据、预注册假设与对照设计见 [PLAN-v4.md](PLAN-v4.md)。

## 环境

需要 **PyTorch XPU** 轮子（Intel Arc 显卡）：

```bash
python -m venv .venv
.venv/Scripts/python -m pip install torch --index-url https://mirror.sjtu.edu.cn/pytorch-wheels/xpu
.venv/Scripts/python -m pip install numpy h5py pytest
python -c "import torch; print(torch.xpu.is_available())"
```

**用 SJTU 镜像**：实测 815 KB/s，官方源 166 KB/s，快 4.9 倍。

注意事项：

- **不要安装 `intel-extension-for-pytorch`**：IPEX 已于 2026 年 3 月 EOL。
- 本机无 MSVC，**`torch.compile` 在 XPU 上不可用**，只能 eager。
- 消费级 Arc **无 FP64**（`has_fp64=0`），所有 float64 校验必须放 CPU。
- **训练批大小 ≥ 512**：类 SNN 负载在内核启动受限区，B=128 时 GPU 几乎无收益。
- **AdLIF 训练不要并发**：它的正反馈回路处在发散边界，并发扰动会触发 NaN。
