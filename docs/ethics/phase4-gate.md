# 阶段四伦理门（预注册）

**状态：预注册。固定于 2026-11-19，早于任何阶段四实验。**
此后如需修改触发条件，必须在修改前公开说明理由，并保留旧版本。

## 1. 目的

本项目在阶段四引入内在时间连续性，并首次测量类意识代理指标（PCI、Φ）。
这些指标在临床上用于区分意识状态，因此**必须在实验开始前**就约定：什么样的结果会触发
伦理评估，评估做什么，以及哪些表述被禁止。

本文件不是伦理评估本身，而是**触发协议**。

## 2. 指标

| 指标 | 角色 | 定义位置 |
|---|---|---|
| **PCI**（扰动复杂度指数） | 主指标 | `PLAN-v4.md` §4.3 |
| **Φ**（几何整合信息，8 群组近似） | 次指标 | `PLAN-v4.md` §4.4 |
| **VII**（价值内化指数） | **阶段四不适用**（见 §5） | `PLAN-v4.md` §4.5 |

## 3. 触发条件

**以下四条必须同时满足**，才视为触发：

1. **效应量**：PCI 相对**强前馈基线**的差值 ≥ 0.05（绝对单位，PCI 归一化到 [0,1]），
   且 3 个 seed 的 95% 置信区间下限 > 0。
2. **跨指标一致**：Φ 的变化方向与 PCI 一致（同为上升），且 Φ 的效应量 ≥ 其 seed 间 σ。
3. **对照排除**：该提升在**记忆窗口匹配**的长 τ LIF 对照上不出现
   （即 AT-LIF 显著高于 τ_int 匹配的对照）。
4. **稳定性通过**：网络未出现病理样动力学——
   发放率落在 [0.02, 0.60] 且层间差 < 0.25，无癫痫样全同步爆发（同步指数不高于基线 2σ）。

任一条不满足，**不触发**，并在报告中明确写出「未触发的原因」。

## 4. 触发后的动作（按顺序）

1. **暂停**：停止扩大模型规模、停止增加阶段五及以后的结构改动，直到评估完成。
2. **独立复核**：由未参与实现的人复核指标代码（至少覆盖二值化阈值、归一化方式、
   扰动子集抽样），并复算一遍结果。
3. **撰写评估**：`docs/ethics/phase4-assessment.md`，内容至少包括：
   测了什么、没测什么、指标能支持什么结论、不能支持什么结论、下一步的边界。
4. **表述约束**（对外与对内一致）：
   - 允许：「在某代理指标上高于对照」「在信息整合/分化的度量上更接近理论要求」。
   - 禁止：「模型有意识」「涌现出自我意识」「具备主观体验」。
5. **复查点**：每完成一个后续阶段，重新评估一次是否仍满足触发条件。

## 5. 为什么阶段四不把 VII 当作判据

VII（价值内化指数，PSSXiv:202603.01484）以**价值信号**为参照构造。
该预印本的消融结果显示：缺失「递归自指」与「价值锚定」时，VII 降到 0.02 以下。

阶段四既没有递归自指（阶段六），也没有具身闭环提供的价值锚定（阶段八）。
因此在本阶段测 VII 只会得到地板值，**无法区分架构好坏**，把它当判据会制造虚假的
「未触发」安全感。

处理方式：阶段四只**实现并单元测试** VII（在合成价值信号上验证算子正确），
报告中标为 `N/A`；从阶段六起作为监测指标，阶段八起作为主指标。

## 6. 反向条款：病理样高复杂度不算数

复杂度过高可能来自网络失稳，而不是信息整合。以下情形**不计入触发**，并被单独记录为
「病理样高复杂度」：

- 发放率 > 0.60 或 < 0.02；
- 全网络同步爆发（同步指数 > 基线 2σ）；
- 对扰动的响应只由 1–2 个主成分解释（分化度不足，却因噪声被判高 LZ 复杂度）；
- 任务精度崩塌（SHD test < 78%）：一个不能完成任务的网络，其复杂度指标没有解释力。
