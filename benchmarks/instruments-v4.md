## 3. 三个仪器可用，一个不可用

### 3.1 ITC：可用，但阈值要改口径

- 判别力成立：LIF 撤输入后归零（`tau_int` 1.0），TC-LIF 维持 **39–42 帧**的相关长度。
- **但自持比必须按网络平均看**：TC-LIF 是 0.12 / 0.58，单看 L0 会判失败。
  计划里写的「≥ 0.30」需改为「**两层平均 ≥ 0.30**」（TC-LIF 平均 0.35，LIF 平均 0.10）。
- 另一个必须在报告里写的发现：**训练后的 AdLIF 已经表现出内在连续性**
  （L1 自持比 0.89、`tau_int` 35.6）。也就是说「无输入时仍有活动」不是 TC-LIF 独有的，
  适应电流本身就能提供。这对 M2 的动机有直接影响（见 §4）。

### 3.2 GSA：可用，但预期方向被推翻

- 尺子本身正确：随机 LIF 的 β ≈ 1.03–1.07（线性区），训练后 LIF 降到 0.59（阈值非线性）。
- **但「长 τ 会失去梯度敏感性」在初始化时不成立**：随机 LIF τ=200 的 β=1.03，
  与 τ=2 几乎相同。原因是未训练网络的权重小、膜电位远未饱和，长 τ 只是把输入积分得更久。
- **TC-LIF 的 β=0.82，比训练后 LIF 的 0.59 更高**——它并没有失去幅度敏感性。
  计划中「必须叠加 AdLIF 才能保住 GSA」的前提，在 M0 的数据上**没有得到支持**。
- 反而 AdLIF 的 β=0.42 是五个网络里最低的：适应电流作为增益控制，本身会压缩幅度敏感性。

### 3.3 PCI：可用，但必须用「扰动诱发」口径

第一版用「相对扰动前 20 帧均值的 z-score」，在振荡网络上完全失效：
TC-LIF 的 PCI 0.536 里有 **0.528 来自它自己的持续活动**（密度 0.669），
扰动只贡献 0.008。改成 `|扰动轨迹 − 无扰动轨迹|` 后（模型在 eval 下确定性，
差值就是纯扰动效应），数值才有意义。

阈值也必须用**绝对量**（膜电位移动 > 0.05，即 10% 阈值），不能用「扰动前标准差」归一化——
训练后网络的自身波动很大，3σ 等于不可达（实测 amp=100 时密度仍只有 0.0026）。

剂量曲线（训练后 LIF）：`amp=10 → PCI 0.0362 / 密度 0.047`，
`amp=30 → 0.0322 / 0.057`。**更强的扰动让密度上升、复杂度下降（饱和）**，
所以 `amp=10` 是当前协议的操作点。

### 3.4 Φ_G：**暂不可用**（本阶段的结论）

- 数值能算，但排序与 PCI 矛盾：随机网络 Φ_G 高达 82.7 / 40.9，训练后网络只有 0.55 / 1.84。
- 原因很可能是随机网络的所有群组被同一输入强驱动，协方差高度相关，
  最小二分 KL 因此很大——这是「共同驱动」而不是「整合」。
- 处理：Φ_G **降级为诊断量**，不参与 M3 的判据；M3 之前必须先在已知案例上验证
  （例如两个耦合振子 vs 两个独立振子，前者 Φ 应更高）。在此之前，报告里只列数值、不下结论。

### 3.5 解码 R²（ITC-3）：**不可用**

五个网络里四个为 0（唯一非零的随机 LIF τ=200 是 0.23）。
「从 t 的状态回归 t−30 的输入通道数」这个任务对 384 维线性读出太难，
而且输入置零后标签方差塌缩。**M1 必须换设计**：改为「脉冲身份解码」——
t=0 注入 8 种固定输入模式之一，在 t 时刻做 8 分类（机会 12.5%）。

## 4. 对计划的三个直接修正

1. **ITC-1 的判据改为两层平均**（≥0.30），并记录逐层值；单层会误判。
2. **ITC-3 换成脉冲身份解码**（8 分类），不再用回归 R²。
3. **H4.2 的前提需要重写**：M0 显示 TC-LIF 的 GSA 优于训练后 LIF（0.82 vs 0.59），
   AdLIF 反而更低（0.42）。所以「叠加 AdLIF 是为了保住 GSA」这个理由不成立。
   M2 的 2×2 仍然要做，但假设改为双向：
   - 若 AT-LIF 的 GSA ≥ max(TC-LIF, AdLIF)，则组合是协同；
   - 若介于两者之间，则 GSA 由两者折中决定；
   - 若低于两者，则组合有害。
   **不能因为"计划里写了"就假定协同存在。**

另有一处正面证据：TC-LIF 在 M0 就表现出 39–42 帧的内在时间尺度，
且 `in_scale=5` 下发放率 0.341（未饱和）。ITC 这个结构性要求是可达的。

## 5. 冻结的协议（M1 起不再改）

| 项 | 取值 |
|---|---|
| ITC 输入窗口 | 前 50 帧真实输入，之后 250 帧全零 |
| ITC 统计窗口 | 后 125 帧（跳过惯性衰减） |
| ITC-1 | 两层平均自持比 ≥ 0.30，且平均 `rate_after` ∈ [0.02, 0.60] |
| ITC-2 | 两层平均 `tau_int` ≥ 20 帧 |
| ITC-4 | `participation_ratio` ∈ [2, 50] |
| GSA | α ∈ {0.25, 0.5, 1, 2, 4}，β ∈ [0.5, 1.5]，g(4)/g(1) ≥ 1.5 |
| PCI | `amp=10`、`abs_thresh=0.05`、20 次扰动、t0=20、t_resp=60、10% 神经元 |
| Φ_G | 仅诊断，不作判据 |
