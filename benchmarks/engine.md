# 推理引擎基准

- 平台：Intel64 Family 6 Model 151 Stepping 2, GenuineIntel / Windows / Python 3.12.4
- 模型：`freebird-lif-T4.pt`，T=4，参数 40798
- 样本：10000 条官方测试集；单样本延迟取 1000 次重复的 p50/p99
- 批量吞吐：4096 条重复 8 次取均值

## 精度复核

| 引擎 | 测试精度 |
|---|---|
| L1-numba-sparse | 0.9897 |
| L1-numba-dense | 0.9897 |
| L0-numpy | 0.9897 |

## 单样本延迟（B=1）

| 引擎 | p50 | p99 |
|---|---|---|
| L1-numba-sparse | 0.136 ms | 0.507 ms |
| L1-numba-dense | 0.329 ms | 1.079 ms |
| L0-numpy | 0.987 ms | 2.256 ms |

## Conv1 内核对比（与 t 无关，每样本只算一次）

| 实现 | B=512 摊销 | B=1 单次 |
|---|---|---|
| 融合直算（默认） | 1.55 µs/样本 | 11.6 µs |
| im2col + GEMM | 24.91 µs/样本 | – |

12 个输出通道使 GEMM 的 K 维只有 9，整段退化为带宽受限；融合内核把 12 个
累加器保持在寄存器里，避免 im2col 的两次全量拷贝。
